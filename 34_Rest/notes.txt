=============================================REST====================================================================== 
Representational state transfer 
Rest is an architecture style that defines a set of constraints to be used for creating web services.
Restful API's -> APIs(Application Programming Interface) which satisfies Rest rules , used to perform CRUD operations

CRUD - Create , Read , Update , Delete

POST   -  (create a record)
GET    -  (retrieve a record)
PUT    -  (update a record)
PATCH  -  (update specific record)
DELETE -  (delete the record)

status code starts with 2(all ok) , 3(response redirect) ,5(server internal error occur)

========> res.redirect([status,] path) <=============

Redirects to the URL derived from the specified path, with specified status, a positive integer that corresponds to an HTTP status code. If not specified, status defaults to 302 "Found".

res.redirect('/foo/bar')
res.redirect('http://example.com')
res.redirect(301, 'http://example.com')
res.redirect('../login')
